Same Accuracy, Different Trajectory:
Measuring Reasoning Regimes in Masked Diffusion Language Models

Adele Chinda · Department of Computer Science, Georgia State University

Final-step accuracy treats a diffusion language model that locks in its answer at step 3 and spends 250 steps backfilling a post-hoc rationale identically to one that deliberates across the canvas before committing. traj-eval instruments the full denoising trajectory t = 1 … T using three-clock decomposition—verdict stability (Tstab), answer token commitment (Tcommit), and rationale unmasking fraction FR(t)—across ARC-Challenge and GSM8K.

            Paired Condition Analysis
            
Direct vs. Canonical Reasoning & Item-Level Scatter

          

          

            Paired 64-item evaluations on ARC-Challenge reveal opposite deliberation effects across model families: forcing rationale-first generation slightly hurts Dream-v0-Instruct-7B (−6.25 pp) while improving both LLaDA-8B-Instruct (+3.12 pp) and VRPO-tuned LLaDA-1.5 (+4.69 pp).

Reproduce or Score Runs via CLI

            
# 1. Install traj-eval in editable mode (zero heavy deps for scoring)
pip install -e ".[dev]"
pytest -q

# 2. Score any trajectory JSONL & compare paired conditions
traj-eval score results/llada_15_arcc_smoke64_reasoning.jsonl \
  --compare results/llada_15_arcc_smoke64_direct.jsonl \
  --label-base direct_64 --label-target reasoning_64
