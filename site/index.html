traj-eval

Measure reasoning in the denoising trajectory, not just final-answer accuracy.

Two models can have identical final-answer accuracy for very different reasons: genuine reasoning, rationalization, and oscillation. Final-step evaluation collapses the entire denoising process into a single endpoint prediction, hiding when a verdict stabilized and how the intermediate rationale developed. traj-eval instruments and scores the full step-by-step denoising trajectory so these reasoning regimes can be distinguished.

Section 1

Why accuracy lies

Evaluating only the final denoised output treats three distinct trajectory behaviors as identical whenever they end on the same answer:

Genuine reasoning

Reasoning drives verdict

The verdict changes as reasoning develops across intermediate denoising steps, then stabilizes once the derivation supports a conclusion.

Rationalization

Verdict drives reasoning

The verdict is fixed in the first few steps, and reasoning text is elaborated afterwards to justify the already locked-in answer.

Oscillation

Unsettled trajectory

The verdict flips repeatedly across denoising steps and never settles until the final step, even if the final answer happens to be right.

Synthetic Demo Only (Not Model Evidence)

v0.1 Synthetic Benchmark (examples/synthetic_demo.jsonl)

In the built-in 15-trajectory synthetic demo (5 trajectories per archetype), every trajectory ends on the correct gold answer (final accuracy = 1.0000 for all three archetypes). Final-answer accuracy cannot tell them apart; trajectory metrics separate them cleanly. This v0.1 split is synthetic and is used for pipeline demos and unit tests, not as evidence about any real model checkpoint.

        Section 4
        
Metrics (definitions only)

        

          Operational definitions implemented in src/traj_eval/metrics.py. See the full README metrics table for ranges and edge-case rules.
        


        

          

            
Verdict convergence step (verdict_convergence_step)

            

              First denoising step Tstab after which the extracted prediction stays constant to the end of the trajectory. Under the null rule, None means no verdict was extracted at that step (not a verdict flip), and returns None if the final step has no extracted verdict.
            

          


          

            
Flip rate and consistency (flip_rate, step_consistency)

            

              flip_rate measures the fraction of adjacent decided step pairs where the extracted prediction changes (0.0 = never changed, 1.0 = changed at every decided transition). step_consistency reports 1 - flip_rate together with the longest stable run of identical predictions.
            

          


          

            
Trajectory accuracy (trajectory_accuracy)

            

              Fraction of trajectories where the final step prediction matches the gold answer, accompanied by coverage (fraction of trajectories with a non-null final prediction) and conditional_accuracy (accuracy among decided trajectories).
            

          


          

            
Rationalization components (rationalization_components)

            

              Heuristic (descriptive, not causal proof). Decomposes post-verdict text activity into early_factor = 1 - conv_idx / n, post_change_rate (fraction of post-convergence steps where reasoning text changes), length_growth (relative character growth after convergence), additive score, and multiplicative gated_score.
            

          


          

            
Commitment clocks (answer_commitment_step, stability_commitment_lag, unwritten_reasoning_at_convergence)

            

              Tracks Tcommit (first step where the answer token span in the canvas stays unmasked through the final step), the stability lag Tcommit − Tstab in steps, and unwritten reasoning at convergence 1 - committed_reasoning_fraction at Tstab.
            

          

        

      

    


    
    

      

        Section 5
        
Install and quickstart

        

          Requires Python 3.10 or newer and numpy only. No model weights, no torch, and no transformers are needed to install the package or run the demo.
        


        

          

            
CLI quickstart

            
pip install -e .
python -m traj_eval demo
python -m traj_eval run --input examples/synthetic_demo.jsonl --output results.json

          


          

            
Python API

            
from traj_eval.io import load_trajectories
from traj_eval.metrics import evaluate_trajectories

trajs = load_trajectories("examples/synthetic_demo.jsonl")
results = evaluate_trajectories(trajs)
print(results["aggregate"])

          

        

      

    


    
    

      

        Section 6
        
Caveats

        

          
    
            
  • 
              Descriptive, not causal proof: traj-eval measures when verdicts and rationale tokens appear and change along the denoising trajectory. It does not prove internal causal mechanisms.
            
    • 
            
  • 
              Operational definition of rationalization: A high rationalization score means a trajectory looks like rationalization by this operational definition (early verdict stabilization followed by continued text edits or length growth), not that the model is proved to be rationalizing.
            
    • 
            
  • 
              Five-item runs are pipeline checks only: Five-item smoke runs are used solely as pipeline and extraction sanity gates and are not included in the results table above.
            
    • 
            
  • 
              Holdout checkpoint status: MMaDA-8B-MixCoT has not been run yet.
